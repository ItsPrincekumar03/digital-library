# Digital Library — Feature List

## 1. Purpose

This document provides a structured inventory of the features associated with the Digital Library project.

The feature list is intended to help:

- Understand the complete product scope
- Plan development
- Map features to modules
- Create test coverage
- Track implementation status
- Support academic documentation
- Provide context to AI coding assistants

A feature listed in this document is not automatically considered implemented.

Implementation status must be verified against the current source code, database, tests, and other available evidence.

---

# 2. Feature Status Definitions

The following status values should be used when tracking features:

| Status | Meaning |
|---|---|
| PLANNED | Feature is planned but development has not started |
| IN_PROGRESS | Feature is currently being developed |
| IMPLEMENTED | Code exists but complete verification may not be finished |
| VERIFY | Existing implementation requires current verification |
| VERIFIED | Feature has been tested and supported by evidence |
| BLOCKED | Feature cannot proceed because of an unresolved dependency |
| FUTURE | Feature is intended for a later version |
| NOT_APPLICABLE | Feature does not apply to the current implementation |

The status should never be upgraded without evidence.
