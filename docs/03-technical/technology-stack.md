# Digital Library — Technology Stack

## 1. Purpose

This document defines the approved technology stack for the Digital Library project.

It explains the technologies selected for:

- Frontend development
- Backend development
- Database management
- API communication
- Development environment
- Testing
- Version control
- Security
- Deployment

The purpose of this document is to prevent unnecessary technology changes and to provide a consistent technical baseline for developers and AI coding assistants.

The exact package versions and installed dependencies must always be verified from the current repository.
