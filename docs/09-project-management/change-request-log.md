# Digital Library — Change Request Log

## 1. Document Purpose

This document records significant requested changes to the Digital Library project.

A change request may affect:

- Product scope.
- Requirements.
- Architecture.
- Database.
- APIs.
- Frontend.
- Security.
- Reader.
- TTS/audio.
- Translation.
- Testing.
- Deployment.
- Project schedule.
- Academic deliverables.

The purpose of this document is to prevent important changes from being made silently or without understanding their consequences.

This document is a change-management record.

It does not prove that a requested change was implemented.

The actual repository, database, tests, and runtime behavior remain the source of truth.
