# Digital Library — Project Limitations

## 1. Introduction

Every software system has limitations based on its technology, scope, resources, deployment environment, and development timeframe.

The Digital Library project is designed as a BTech final-year academic project with a controlled V1 scope. Therefore, the limitations described in this document define the boundaries within which the system is intended to operate.

These limitations should not be interpreted as defects unless a documented requirement explicitly requires behavior beyond the stated boundary.

---

# 2. Project Scope Limitation

The project is intentionally limited to the functionality approved for the V1 release.

The V1 system focuses primarily on:

- User authentication
- User and administrator access control
- Category management
- Book management
- Chapter management
- Publication and visibility control
- Library discovery
- Online reading
- Reader customization
- Reading progress where implemented
- Auto-scroll where implemented
- Text-to-speech/audio functionality where implemented
- Translation where implemented
- Security
- Testing
- Deployment preparation

Features outside the approved V1 scope are considered future enhancements unless formally approved.
